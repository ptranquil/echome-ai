# Route Mobile Limited

I was a Software Developer at Route Mobile Limited, February 2024 to June 2025.

Stack: Node.js, TypeScript, AWS Lambda, API Gateway, S3, DynamoDB, CloudWatch, Docker, ECR, REST APIs.

What I did:

- Microservices on AWS, using Lambda, API Gateway, S3, and DynamoDB.
- REST API and database-query work aimed at lower latency.
- RBAC for parent-child account management and authorization.
- I migrated Node.js applications from EC2 to AWS serverless (Lambda, API Gateway, ECR, DynamoDB), which reduced infrastructure cost and sped up deploys.
- Production troubleshooting with CloudWatch logs and metrics.
