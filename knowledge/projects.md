# Projects on my portfolio

## Enterprise workforce and operations platform

I built a modular enterprise system across web and mobile: workforce operations, reporting, and cloud integrations.
The stack includes Angular, Ionic, React, Node.js, TypeScript, Firebase, Firestore, BigQuery, PostgreSQL, Redis, Docker, AWS, and GCP.
When someone asks what I do day to day, I talk about the iSITE work. When they ask about this portfolio case study, I use this broader title.

## AWS serverless migration

I moved production Node.js from EC2 to AWS Lambda and API Gateway, with Docker images in ECR, DynamoDB, and CloudWatch.
The point of the story is elasticity, lower infrastructure cost, and a repeatable deploy. This overlaps my Route Mobile role.

## ONDC logistics platform

I worked on order lifecycle management with ONDC and Beckn protocol integrations.
Stack: Node.js, Express.js, RabbitMQ, Redis, Docker, MySQL, React.js.
Queue-based processing, retries, and idempotency for network callbacks.

## Real-time tracking dashboard

I built an operational dashboard for industrial fleet conversion: live status, billing tied to milestones, Redis on the hot path.
Stack: React.js, Node.js, TypeScript, MongoDB, Redis, Docker.

## Shopify payment application

I built custom Shopify payment and refund flows.
Stack: PHP, Java, Shopify APIs, GraphQL, AWS EC2.
GraphQL for merchant configuration. PHP and Java services on EC2 for transaction handling.
