# Synergy Technology Services

I was a Software Engineer at Synergy Technology Services Pvt Ltd, April 2021 to January 2024.

Stack: Node.js, Express.js, React.js, TypeScript, MongoDB, MySQL, PostgreSQL, Docker, RabbitMQ, Redis.

What I did:

- API-centric backends using modular structure and microservices for client systems that needed to stay up.
- Faster API responses through indexing, query tuning, and backend refactoring.
- Backend delivery on multiple client projects, working with frontend teams on API design.
- Code reviews, testing, and performance work to keep production stable.

The ONDC logistics platform and the real-time fleet tracking dashboard are project stories from this period. I can go into those if you ask about the projects.
